# 단붕봇 개인정보 처리방침

시행일: 2026-10-01

단붕봇(이하 "봇")은 Discord 서버에서 가상 화폐 게임과 편의 기능을 제공하는 봇입니다. 이 방침은 봇이 어떤 정보를 수집·이용·보관하는지 설명합니다.

## 1. 운영자 및 연락처
- 운영자: Felnut
- 문의·삭제 요청: **dev@felnut.com**

## 2. 수집하는 정보
봇은 기능 제공에 필요한 최소한의 정보만 저장합니다.

| 정보 | 사용 목적 |
|---|---|
| Discord 사용자 ID | 유저 식별, 지갑·랭킹·송금·게임 기록 연결 |
| 보유 금액(가상 화폐) | 경제·게임·랭킹 기능 |
| 출석 기록(마지막 출석일, 연속 출석 일수) | 출석 보상 계산 |
| 주식 보유 내역(종목, 수량, 평균 매수가) | 주식 기능, 주식 랭킹 |
| 진행 중인 숫자야구 게임 상태(정답, 시도 기록) | 게임 진행 및 재시작 후 복구 |

랭킹과 송금 결과 화면에는 사용자 멘션(닉네임)이 표시될 수 있습니다.

## 3. 수집하지 않는 정보
- 이메일, 전화번호, 실명, 주소, 결제 정보는 수집하지 않습니다.
- 채팅 메시지는 저장하지 않습니다. 봇은 숫자야구 진행 중인 사용자의 4자리 숫자 입력을 판정하기 위해 메시지를 일시적으로 읽을 뿐이며, 내용은 기록하지 않습니다.
- `/급식` 명령은 공공 API(NEIS)에 학교 급식 정보를 요청하며 사용자 정보를 전달하지 않습니다.

## 4. 보관 및 파기
- 정보는 봇 서버의 SQLite 데이터베이스에 저장되며, 서비스 이용 기간 동안 보관합니다.
- 삭제를 요청하시면 확인 후 합리적인 기간 내에 해당 사용자의 데이터를 삭제합니다.
- 서비스가 종료되면 저장된 데이터를 파기합니다.

## 5. 제3자 제공 및 처리 위탁
- 수집한 정보를 판매하거나 제3자에게 제공하지 않습니다.
- 봇은 Discord 플랫폼 위에서 동작하며, 운영자가 직접 관리하는 서버에서 실행됩니다. 위 정보는 해당 서버의 데이터베이스에만 저장되고 외부 클라우드에 저장되지 않습니다.

## 6. 이용자의 권리
이용자는 자신의 데이터에 대한 열람, 정정, 삭제를 요청할 수 있습니다. 위 연락처로 Discord 사용자 ID와 함께 요청해 주세요.

## 7. 아동 이용
Discord 이용 약관상 최소 연령 미만의 사용자는 이 봇을 이용할 수 없습니다. 해당 연령 미만의 정보가 저장된 것을 알게 되면 즉시 삭제합니다.

## 8. 방침 변경
방침이 바뀌면 이 문서를 수정하고 시행일을 갱신합니다.
